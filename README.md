# SMART_HEALTH_CARE__DIAGNOSIS
# Smart Disease Predictor System using Machine Learning

A GUI-based system that predicts diseases based on user-input symptoms using multiple machine learning classifiers. This tool helps in preliminary disease diagnosis and enhances decision-making in healthcare.

---

## Features

- Takes **up to 5 symptoms** from the patient.
- Supports **multiple machine learning models**:
  - Decision Tree
  - Random Forest
  - Naive Bayes
  - K-Nearest Neighbors
- Predicts possible diseases using each algorithm separately.
- Built with an easy-to-use **Graphical User Interface (GUI)** using **Tkinter**.
- Includes features like:
  - **Prediction buttons** for each algorithm.
  - **Reset Inputs** to clear all fields.
  - **Exit System** to close the application.
